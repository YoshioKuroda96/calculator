基本の計算 =

式をまとめて入力し、= を押すと答えが履歴に追加されます。掛け算・割り算が先に計算されます。

答えの表示

ルール例
小数点以下3桁まで（4桁目を四捨五入）2/3 → 0.667…
続く場合は末尾に …1/3 → 0.333…
割り切れるときは … なし、末尾の 0 も省略1/4 → 0.25
3桁ごとにカンマ1234567/7 → 176,366.714…

便利な書き方

  • 掛け算の省略：2(3+4) → 14、2π → 6.283…
  • パーセント：200×10% → 20
  • 閉じかっこの省略：(1+2 のまま = を押しても自動で閉じて計算します。
  • AC は入力欄だけを消します。履歴は残ります。

式の編集 ◀▶⌫

操作動作
◀ ▶カーソルを1つ移動します。分数・指数・ルートの枠の出入りにも使います。
式をタップタップした位置にカーソルが移動します。式の途中に数字や記号を入れられます。
⌫カーソルの左を1つ消します。
AC入力欄を全部消します。

分数・指数・ルート /xʸ√

押すと数式どおりの形で表示され、▶ を押すまで枠の中に入力が続きます。+ や × を押しても枠から出ないので、かっこなしで複数の項を入れられます。

12+2 + 21+2 + √9+7
キー表示枠から出る
/分数。分子は直前の数（またはかっこ・関数）、カーソルは分母へ▶
xʸ数字の右上に小さく入る（指数）▶
√数字の上に横線が伸びる▶

入力例

1/2+2▶+1= → 1.25（1/(2+2)+1）

  • 分子を複数の項にしたいときは、先にかっこで囲みます：(1+2) → / → 3
  • 点線の空の枠 をタップすると、そこへカーソルが移動します。
  • 枠のすぐ右で ⌫ を押すと、枠の中へ戻ります。空の枠で押すと枠ごと消えます。

ans と履歴 ans

ans（直前の答え）

  • ans は直前の答えです。単位つきの答えなら、単位も引き継ぎます。
  • 入力欄が空のときに + − × / xʸ % を押すと、自動で ans から始まります。続けて計算したいときに便利です。
  • 履歴には ans と表示されず、さかのぼった元の式で表示されます（例：(2+3)×4−1）。

履歴をタップ（INSERT のとき）

タップする場所動作
答えカーソル位置に答えを挿入（単位つきなら単位も）
式カーソル位置に式を挿入。入力済みの式は残り、かっこで囲んで入ります（7× のあとに 2+3 をタップ → 7×(2+3)）
単位（点線付き）同じ種類の単位の候補を表示。選ぶと変換結果が新しい行に入ります

方程式の行の式は、入力欄が空のときだけ呼び出せます。履歴は最大300件まで、この端末に保存されます。

INSERT / CLIP COPY INSERTCLIP COPY

DEG の右のボタンを押すたびに INSERT ⇄ CLIP COPY が切り替わり、履歴をタップしたときの動作が変わります。設定は保存されます。

状態履歴をタップしたときの動作
INSERT入力欄へ挿入（コピーしない）
CLIP COPYクリップボードへコピー（入力欄は変わらない）

コピーされる内容（CLIP COPY のとき）

タップした場所コピーされる文字
答え：15,000 mm15000 mm

  • コピーした「式 = 答え」をこの電卓に貼り付けると、式の部分だけが入ります。

方程式（X を求める） X

X を含む式を入れると、= ボタンの表示が変わり、左辺・右辺の順に入力して X を求められます。

  1. X を含む左辺を入力します：2X+3
  2. ボタンが = 右辺へ に変わるので押します。式に = が入ります。
  3. 右辺を入力します：7
  4. ボタンが X を求める に変わるので押します。
  5. 履歴に X = 2 が表示されます。
方程式結果
2X+3 = 7X = 2
X² = 9X = −3, 3（解が複数ならすべて）
√X = 3X = 9
2^X = 1024X = 10
sin(X) = 0.5（DEG）X = −330, −210, 30, 150, 390, …
X+1 = X+2解なし
X+1 = X+1すべての X
  • 解が多いときは、0 に近い順に最大5個を表示します。
  • 求めた X は ans に入ります（解が複数なら一番小さいもの）。
  • 1次式は正確に解き、それ以外は ±1,000,000 の範囲で数値的に探します。
  • = を ⌫ で消すと、= 右辺へ の状態に戻ります。

方程式では単位は使えません。

単位の計算と変換 単位→

単位 を押すと、関数の2段が単位のボタンに切り替わり、% の位置が →（変換）になります。もう一度押すと元に戻ります。

式の中で単位を使う

数字の直後に単位キーを押します：5m/min×3min= → 15 m

計算と結果答えの単位の決まり方
5 m/min × 3 min
→ 15 m		単位が約分される
15 m ÷ 3 min
→ 5 m/min		式の単位を組み合わせる
36 m/h × 2 h
→ 72 m		単位が約分される
100 mm + 2 m
→ 2,100 mm		足し算・引き算は左側の単位にそろう
2 m × 3 m
→ 6 m²		当てはまる単位がなければ組み合わせて表示
10 kg × 9.8 m/sec ÷ sec
→ 98 N		N になる組み合わせは N で表示

答えを別の単位に変換する

  • → キー：15m→mm= → 15,000 mm
  • 入力欄が空のときに → を押すと、直前の答えを変換します。
  • 履歴の答えの単位の部分（点線付き）をタップ → 候補から選ぶと、変換結果が新しい行に入ります。

kg と N の換算

kg を「kg重」とみなし、1 kg = 9.80665 N で換算します。

入力結果
5 kg → N49.033… N
100 N → kg10.197… kg

kg と N は → での換算だけ。足し算・引き算で混ぜることはできません。

種類の違う単位の足し算（3 m + 2 kg）、sin・log などの中の単位、違う種類への変換（5 m → kg）はエラーになります。

ホーム画面に追加・更新

公開ページをホーム画面に追加すると、アプリのように起動できます。一度開けば、以降は圏外でも使えます。

https://yoshiokuroda96.github.io/calculator/

端末手順
iPhoneSafari で開く → 共有ボタン → ホーム画面に追加
AndroidChrome で開く → ︙ → ホーム画面に追加（またはアプリをインストール）

新しい版にするには

  • スマホ：アプリを完全に閉じて開き直します。変わらなければもう一度。
  • パソコン：Ctrl+Shift+R で再読み込みします。

履歴と設定（DEG・INSERT / CLIP COPY・単位キーの状態）は、その端末のブラウザだけに保存されます。ブラウザのデータを消すと、履歴も消えます。
